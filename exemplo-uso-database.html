📖 Como usar no seu jogo:

1. Adicione as bibliotecas no seu HTML:

<script src="https://cdnjs.cloudflare.com/ajax/libs/sql.js/1.8.0/sql-wasm.js"></script>
<script src="src/scripts/database.js"></script>
<script src="src/scripts/leaderboard.js"></script>

2. Inicialize o banco quando a página carregar:

// No seu script do jogo
window.addEventListener('load', async () => {
    await gameDB.init();
    console.log('Banco inicializado!');
});

3. Salve recordes quando o jogo terminar:

// Quando o jogo termina
const leaderboard = new Leaderboard('Mira Bamba');
const result = await leaderboard.saveScore(
    pontuacao,  // pontuação do jogador
    nivel,      // nível alcançado (opcional)
    tempo       // tempo jogado em segundos (opcional)
);

4. Mostre o ranking:

// Exibe top 10
const leaderboard = new Leaderboard('Mira Bamba');
await leaderboard.displayRanking('ranking-container', 10);
